# Playwright – eBay Related Products Automation

## 📌 Project Overview
This project automates testing of the **Related Best Seller Products** feature on an e-commerce product page using **Playwright**.

---

## 🛠 Tech Stack
- Playwright
- TypeScript
- Page Object Model (POM)

---

## 📂 Project Structure
- `pages/` – Page Objects
- `tests/` – Test scripts
- `playwright.config.ts` – Configuration
- `package.json` – Dependencies
